                              Computers running Whisper
                              
      
                              Each episode is transcribed whole on one computer, so several episodes are transcribed at once.
        These computers only transcribe; the AI that finds ads is set in the AI tab. If one fails, its episode goes to another (in the end, this PC).
                              
      
                                
      
                                
        
        
        
        
        
        
      
                                
      
                                
        
      
                                
      
                                
        How to set up another computer
        
                                
          
                                speaches (faster-whisper; best with an Nvidia GPU). With Docker:
            docker run --detach --restart unless-stopped --publish 8000:8000 --volume hf-hub-cache:/home/ubuntu/.cache/huggingface/hub --gpus=all ghcr.io/speaches-ai/speaches:latest-cuda
            (without an Nvidia GPU: the latest-cpu image, no --gpus=all). Podcast Cleaner asks it to download the Whisper model
            the first time — the same one as this PC's Model setting, unless you type another (e.g. Systran/faster-whisper-large-v3).
                                
          
                                whisper.cpp server (AMD or Intel graphics via Vulkan, or CPU). Build it with build-whisper-vulkan.ps1, then run
            whisper-server -m ggml-large-v3-turbo-q5_0.bin --host 0.0.0.0 --port 8080. The model is the one you start it with.
                                
          
                                On each computer, allow the port (8000 or 8080) in Windows Firewall for your home network only.
